# 09.24 - Definition Of Done

This checklist is the gate for Chapter 09. Do not move on until every item is true in your own project.

- [ ] Project management screens exists in the repo.
- [ ] The main route, screen, table, or function for `project management` can be opened or inspected.
- [ ] The happy path has been tested.
- [ ] A failure, empty, or validation state has been tested.
- [ ] A privacy or secret-safety check has been tested where relevant.
- [ ] `learning-log/09-admin-project-crud.md` explains the decision and the proof.

All boxes ticked? Then continue to the next chapter. If not, that is where today's work is.
