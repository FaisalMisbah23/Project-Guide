# 09.01 - Set The Scene

The project now needs **project management**. This chapter adds project management screens while keeping the portfolio understandable for a beginner and reviewable by a mentor.

The story of this chapter is simple: a portfolio becomes maintainable when content updates are part of the product, not a database chore. You will build the professional version from the start, but you will still understand why the tempting shortcut fails.

By the end, `learning-log/09-admin-project-crud.md` will explain what you built and why it matters.
