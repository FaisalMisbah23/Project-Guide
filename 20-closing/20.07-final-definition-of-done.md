# 20.07 - Final Definition Of Done

This checklist is the gate for Chapter 20. Do not move on until every item is true in your own project.

- [ ] Final demo and next-step plan exists in the repo.
- [ ] The main route, screen, table, or function for `project closure` can be opened or inspected.
- [ ] The happy path has been tested.
- [ ] A failure, empty, or validation state has been tested.
- [ ] A privacy or secret-safety check has been tested where relevant.
- [ ] `learning-log/20-closing.md` explains the decision and the proof.
- [ ] `docs/future-backlog.md` lists only small v2 improvements that do not reopen v1.

All boxes ticked? Then continue to the next chapter. If not, that is where today's work is.
