# 07.03 - What You Will Build

In this chapter you will produce article system.

The visible surface is: articles, article details, pending comments. The protected or owner-facing surface is: draft articles and moderation.

Expected project touchpoints:

```txt
src/features/articles/
src/features/comments/
learning-log/07-articles-comments-search.md
```

Routes or screens involved:

```txt
/articles
/articles/:slug
```

Database areas involved:

```txt
articles
comments
```
