# 01.04 - Scope

Public portfolio:

```txt
Home
About
Skills
Projects
Project details
Articles
Article details with approved comments
Contact
Newsletter signup
```

Admin area:

```txt
Owner login
Dashboard
Project management
Article management
Comment moderation
Contact inbox
Newsletter management
Visitor insights
Image uploads
Live admin updates
```

In scope:

```txt
Vite + React
TailwindCSS + shadcn/ui
Supabase Postgres, Auth, RLS, Storage, Edge Functions, Realtime, Cron
Brevo email
Vercel hosting
Newsletter subscriptions and scheduled updates
Validation, states, accessibility, deployment, maintenance
```

Out of scope:

```txt
Payments
Multi-user teams
Likes
Complex marketing automation
Advanced analytics dashboards
Advanced collaborative editing
Separate Express API
Mobile app
```
