# 01.01 - What you're building

You are building a real, deployed full-stack software engineer portfolio. The frontend is Vite, React, TailwindCSS, and shadcn/ui. Vercel hosts that frontend. Supabase is the backend: Postgres, Auth, Row Level Security, Storage, Edge Functions, Realtime, and Cron. Brevo sends email from Supabase Edge Functions.

This is not a static portfolio. It is a small production-shaped system with public pages, protected admin tools, database-backed content, contact persistence, newsletter subscriptions, scheduled update emails, visitor insights, and deployment.

The product should answer four questions in 30-60 seconds:

```txt
Who are you?
What can you build?
Why should someone trust your work?
How can they contact you?
```

The engineering should answer deeper questions:

```txt
Which data is public?
Which data is owner-only?
Where do secrets live?
What happens when requests fail?
How do Vercel and Supabase work together?
```
