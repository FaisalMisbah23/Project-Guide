# 01.08 - Checklist

This is the gate for **Introduction**. Do not move to the first scaffold chapter until you can prove these orientation outcomes.

## Definition of Done

- [ ] You can describe the finished portfolio product in one sentence.
- [ ] You can name the main audiences and what each one needs.
- [ ] You understand what is in scope and what belongs in future improvements.
- [ ] You have the required tools or know exactly which ones still need setup.
- [ ] You understand the chapter-by-chapter workflow and checklist gates.
- [ ] No secrets, generated dependency folders, or local database dumps are committed.

## Verification

There may not be an app to run yet. Instead, verify the setup state:

```bash
git status
node --version
npm --version
git --version
```

If one of the required tools is missing, install it before starting the project skeleton chapter.

## What you should be able to explain

- What makes this portfolio more than a static resume page
- Why the course builds public pages before admin and deployment work
- Which parts of the app are public-facing and which will be private/admin-only
- How small commits and checklist gates reduce confusion later
