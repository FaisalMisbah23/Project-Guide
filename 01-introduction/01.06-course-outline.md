# 01.06 - Course outline

**Where the project is now:** You know what the course expects. Now preview the road ahead so each chapter feels connected to the final product.

**This step:** Preview the phases and demo targets before writing code.

## Phase 1 - Foundation

You will create the Next.js app, establish the folder structure, add global styling, and build the shared shell. By the end of this phase, the portfolio has a working frame and public pages can begin to feel real.

## Phase 2 - Portfolio proof and data

You will turn projects into structured data, render case studies, add media and diagrams, and introduce Prisma with PostgreSQL. The site moves from presentation to evidence.

## Phase 3 - Publishing workflow

You will build public article routes, admin authentication, dashboard screens, and the article editor. This is where the portfolio becomes maintainable by its owner instead of being edited only through code.

## Phase 4 - Hardening and shipping

You will add revision history, contact handling, shared security checks, metadata, sitemap, robots, headers, analytics, production environment setup, smoke tests, and deployment.

## Closing

The final chapter helps you document the finished work, prepare a demo script, and choose future improvements that raise the quality without hiding the core achievement.

## Continue when

You can match each phase to its demo target and understand why the course starts with structure before database, admin, and deployment work.
