# 01.02 - How to use this course

Work through the course in order. Each chapter is a feature area. Each feature chapter is broken into small ordered sub-chapters so you always know what to do next.

Each chapter teaches the idea, compares weak and better approaches, points to relevant reading, then guides your hands without giving you solution code.

The checklist at the end of each chapter is a gate. Do not move on until every box is true.

Keep a learning log in your project repo:

```txt
learning-log/02-project-foundation.md
learning-log/03-data-model-and-migrations.md
...
```

Write answers in your own words. The learning log is mandatory because it proves you can explain what you built.
