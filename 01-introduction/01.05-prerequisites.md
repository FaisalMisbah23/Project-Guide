# 01.05 - Prerequisites

**Where the project is now:** The scope is set. Before scaffolding the app, confirm the baseline skills and tools the guide assumes.

**This step:** Confirm the React, TypeScript, command line, Git, and database basics assumed by this guide.

## Skills you should have

You do not need to be advanced, but you should be comfortable reading errors and making small changes without panic.

| Area | Expected baseline |
|---|---|
| React | Components, props, lists, forms, and basic state |
| TypeScript | Basic types, interfaces, imports, and compiler errors |
| Terminal | Running commands, stopping dev servers, reading output |
| Git | `status`, `add`, `commit`, branch awareness, and small commits |
| Web basics | Routes, forms, JSON, cookies, and environment variables |
| Databases | Tables, rows, unique fields, relations, and migrations at a basic level |

## Tools you will need

- Node.js and npm
- Git
- A code editor
- A browser with developer tools
- Access to PostgreSQL for the database chapters
- A Vercel account for deployment

## If something is unfamiliar

Pause long enough to learn the concept needed for the current lesson, then continue. Do not try to master every related topic before building. This project is designed to turn concepts into visible behavior.

## Continue when

You have the expected tools available and can honestly identify which prerequisite areas may need slower, more careful work.
