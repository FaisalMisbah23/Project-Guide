# 01.05 - Prerequisites

You should already know basic HTML, CSS, and JavaScript. React and Supabase can be new.

Baseline:

```txt
HTML: semantic tags and forms
CSS: layout, spacing, responsive basics
JavaScript: arrays, objects, promises, modules
Git: status, add, commit, branch, restore
Terminal: folders, commands, errors
```

Revision:

```txt
If HTML/CSS/JS feels rusty, rebuild a small static profile card.
If Git feels rusty, make three small commits in a practice folder.
If async JavaScript feels rusty, revise promises before Supabase data chapters.
```
