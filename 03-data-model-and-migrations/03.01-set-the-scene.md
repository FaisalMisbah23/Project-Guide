# 03.01 - Set The Scene

The project now needs **portfolio database**. This chapter adds Supabase schema while keeping the portfolio understandable for a beginner and reviewable by a mentor.

The story of this chapter is simple: the database becomes the rulebook for the portfolio, not only a storage drawer. You will build the professional version from the start, but you will still understand why the tempting shortcut fails.

By the end, `learning-log/03-data-model-and-migrations.md` will explain what you built and why it matters.
