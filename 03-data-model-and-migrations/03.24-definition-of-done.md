# 03.24 - Definition Of Done

This checklist is the gate for Chapter 03. Do not move on until every item is true in your own project.

- [ ] Supabase schema exists in the repo.
- [ ] The main route, screen, table, or function for `portfolio database` can be opened or inspected.
- [ ] The happy path has been tested.
- [ ] A failure, empty, or validation state has been tested.
- [ ] A privacy or secret-safety check has been tested where relevant.
- [ ] `learning-log/03-data-model-and-migrations.md` explains the decision and the proof.

All boxes ticked? Then continue to the next chapter. If not, that is where today's work is.
