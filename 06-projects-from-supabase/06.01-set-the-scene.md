# 06.01 - Set The Scene

The project now needs **published projects**. This chapter adds project list and detail pages while keeping the portfolio understandable for a beginner and reviewable by a mentor.

The story of this chapter is simple: drafts should never travel to a visitor's browser, even if the UI would hide them. You will build the professional version from the start, but you will still understand why the tempting shortcut fails.

By the end, `learning-log/06-projects-from-supabase.md` will explain what you built and why it matters.
