# Full-Stack React Portfolio Website

You are building a real, deployed **software engineer portfolio** with a real backend: Vite + React on the frontend, Supabase for Postgres/Auth/RLS/Storage/Edge Functions/Realtime/Cron, Brevo for email notifications, and Vercel for deployment.

This guide is written like the old multi-vendor marketplace course: one flat sequence of chapters, each chapter moving the project forward and ending with a gate. Work through the chapters in order. Do not skip a Definition of Done item. Keep a `learning-log/` folder in the project you build, and write the required chapter notes before moving on.
