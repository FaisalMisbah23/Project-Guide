# 17.04 - Final checklist

        This is the gate for **Closing**. Do not move to the next chapter until the product can prove these outcomes in the browser, terminal, or repository.

        ## Definition of Done

        - [ ] The closing work has been committed with a clear message.
- [ ] Mentee has a final demo script, documentation, and bar-raiser list for future improvements.
- [ ] The app still runs locally without unrelated console errors.
- [ ] You can explain why this chapter's main design choice was made.
- [ ] No secrets, generated dependency folders, or local database dumps are committed.

        ## Verification

        Run the checks that fit this chapter. For most build chapters that means:

        ```bash
        npm run lint
        npm run build
        ```

        If a database is required, also run the relevant Prisma command and verify the page or route that depends on it. If a check fails, write down the exact error first, then fix the smallest confirmed cause.

        ## What you should be able to explain

        - What changed in the repo during this chapter
        - Which files are public-facing and which files are private/admin-only
        - How you verified the behavior instead of trusting the code by sight
        - One mistake this chapter helped you avoid
